# Changelog

Notable project milestones are recorded here. Version numbers follow the application package version; these entries do not imply that a GitHub Release has been published.

## 1.0.0 — 14 October 2026

### Added

- Premium, responsive Next.js 16 administrator portal with desktop and mobile layouts.
- Session-based sign-in, protected routes and secure same-origin API forwarding.
- Searchable and filterable doctor and patient directories with pagination and patient management.
- Analytics dashboard backed by the separate Express/MongoDB API.
- Automated type checks, formatting checks, production builds and public smoke tests.
- Verified public Render frontend and backend deployments with synthetic demonstration data.

### Documentation

- Setup, architecture, visual gallery, deployment instructions and live demo links.
- Browser test evidence and scope/limitations in the `docs/` directory.
